# Generator SPPD KONI Kabupaten Tangerang

## Menjalankan secara lokal
1. Instal Python 3.10+.
2. Ekstrak ZIP ini.
3. Buka terminal di folder aplikasi.
4. Jalankan:
   `pip install -r requirements.txt`
5. Jalankan:
   `streamlit run app.py`

File `template_sppd.docx` adalah template asli yang diunggah. Jangan ubah nama file ini.

## Catatan format
Aplikasi mengedit teks di sel tabel template asli agar garis dan struktur tabel tetap berasal dari Word asli. Tetap periksa dokumen hasil karena teks panjang dan perbedaan versi Microsoft Word dapat memengaruhi pembungkusan baris/halaman. Pemetaan field dan sel dapat disesuaikan lebih lanjut.
